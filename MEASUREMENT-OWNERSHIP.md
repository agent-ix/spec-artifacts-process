# Measurement ownership

This repository intentionally owns no active measurement producer or
measurement store in the Project 18 QA portfolio. Its test and specification
surfaces are measured as named inputs by the Quire engine benchmark; copying
those observations here would create two stores for one producer invocation.

If a process-module maintenance metric is introduced later, it must arrive
with an active local plan, a producer that accepts no hand-entered value, and a
plan-valid local collection.
